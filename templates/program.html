Program the panel

Guided installer programming for the ADEMCO VISTA-15P / VISTA-20P (and SIA versions), from the Programming Guide K5305-1PRV5. Every step sends ordinary keypad keys through the EnvisaLink and shows you the panel's own display, so you can check each one.

1. Programming mode

Sends installer code + 8 0 0 (factory code 4112; the code isn't stored or logged). The panel must be disarmed. While programming, the panel doesn't protect the house and the status page may show odd states. Always leave with ✱99 — ✱98 locks out installer-code re-entry until the panel is powered down.

2. What to program

Pick a field on the left. You'll see what it does, its factory default and the choices, and the exact keys that will be sent.

Sets a zone's type, partition, report code and wiring, or enrolls a wireless sensor, using the ✱56 menu (guide page 8). Fill in the form, then work through the steps.

Zone names on the keypad are up to three words from the panel's built-in vocabulary (guide page 11), set in the ✱82 menu. The words below start from the names in this web app; change them, untick zones you want to leave alone, then build the steps.
